# Documentation

This directory contains the public research record for Open Debate Workbench:

- [`architecture.md`](architecture.md) describes the implemented system and
  the two supported debate protocols.
- [`references/du-et-al-2024-multiagent-debate-notes.md`](references/du-et-al-2024-multiagent-debate-notes.md)
  summarizes the reference paper and identifies the reproduced behavior.
- [`reports/small-model-debate-failure-analysis.md`](reports/small-model-debate-failure-analysis.md)
  records the experiment design, aggregate results, limitations, and follow-up
  hypotheses.
- [`reports/small-model-debate-visual-en.html`](reports/small-model-debate-visual-en.html)
  and [`reports/small-model-debate-visual.html`](reports/small-model-debate-visual.html)
  are the publication-ready English and Chinese visual reports.

Raw transcripts, downloaded datasets, databases, and intermediate analysis
outputs are intentionally excluded.
